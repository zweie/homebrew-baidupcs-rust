# Zweie Baidupcs-rust

## How do I install these formulae?

`brew install zweie/baidupcs-rust/<formula>`

Or `brew tap zweie/baidupcs-rust` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "zweie/baidupcs-rust"
brew "<formula>"
```
